# Anotações de estudo

Um arquivo por conceito, escrito com as próprias palavras à medida que cada etapa é implementada.
Cada anotação segue o formato abaixo, pensado para revisão antes de entrevistas técnicas:

1. **O que é**: definição em 2–3 frases
2. **Que problema resolve**
3. **Como foi aplicado neste projeto**: com links para o código
4. **Trade-offs e alternativas**
5. **Perguntas de entrevista**: e as respostas
